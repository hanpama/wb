wb Test Server

This server provides various test scenarios for the wb terminal browser.

1. Instant Load

Page with no additional requests - tests immediate rendering.

2. Slow Resource Loading

Page with slow-loading resources - tests WaitForStable and network status footer.

3. Form Interaction

Form submission without navigation - tests diff rendering.

4. Click Navigation

Link that navigates to new page - tests full re-render on URL change.

5. SPA-style Updates

AJAX updates without navigation - tests diff rendering for same document.

6. Multiple Concurrent Requests

Page that loads many resources - tests request counting and stability detection.

7. Diff Test

Page with buttons that modify content - tests unified diff rendering.
